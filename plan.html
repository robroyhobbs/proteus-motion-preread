This version turns the broader funnel plan into a tighter operating plan: what I would do first, what specific assets I would create, and what inputs I would need from the Proteus team to move quickly.

Core principle

Build on the momentum already there

Important framing: this should build on the brand, content, and community foundation already created — not restart it. The job is to make the funnel clearer, make the proof more visible, and make the sales conversation easier to win.

Days 0-5

Choose the wedge and map the current funnel

Actions

  • Pick the primary wedge to lead with: sports performance, rehab, or facility ROI
  • Walk the current site, booking flow, demo process, and follow-up emails end to end
  • List the top objections, trust gaps, and “why now?” questions buyers still have
  • Review the current proof library: reports, case studies, testimonials, screenshots, video, founder clips

Specific outputs

  • One-page funnel map from first touch to booked conversation
  • One-page objection and trust-gap summary
  • Decision on the first wedge and the specific promise to lead with
  • Alignment with Caley on ownership, approval flow, and weekly review cadence
Days 6-10

Package one flagship proof asset

Actions

  • Select one case study, operator story, or athlete transformation to turn into the lead proof asset
  • Pair the story with the assessment report, visuals, testimonial language, and business case
  • Write the proof stack: headline, tension, evidence, result, and CTA
  • Extract short supporting proof snippets for social, email, and sales follow-up

Specific outputs

  • One flagship proof page or proof pack
  • Three to five proof snippets for sales and marketing reuse
  • One short internal note on how the asset should be used in the funnel
  • One recommended CTA tied to the asset: assessment, demo, or strategy conversation
Days 11-20

Tighten the conversion path

Actions

  • Ship one focused landing path for the chosen wedge with one primary CTA
  • Update the page headline and proof flow so buyers understand the value faster
  • Use the flagship asset to pre-sell the conversation before a sales call happens
  • Mirror the same promise and proof stack in demo invites, email follow-up, and collateral

Specific outputs

  • One wedge-specific landing path
  • One updated follow-up sequence or email template set
  • One sales-facing proof sheet or lightweight leave-behind
  • Clear recommendation on what should change on the website next
Days 21-30

Launch, learn, and sharpen

Actions

  • Publish a short founder-led and proof-led content sequence around the same wedge
  • Track which claims, objections, and proof points create the strongest response
  • Refine the landing path, proof pack, and follow-up based on live conversations
  • Decide whether to deepen the same wedge or repeat the system for the next one

Specific outputs

  • One short content sequence tied to the flagship proof asset
  • One review of what resonated in calls and follow-up
  • One revision pass on the proof pack and conversion path
  • One next-step recommendation for wedge two or for deepening wedge one
By day 30

What should exist by the end of the first cycle

What I’d want shipped

  • One clear wedge-specific message
  • One flagship proof asset that is actually being used
  • One tighter landing path with a single CTA
  • One short founder-led and proof-led sequence
  • One practical set of website and funnel recommendations

What I’d want to learn

  • Which wedge and promise earn the strongest response
  • Which proof points shorten trust-building fastest
  • Which objections still need stronger handling
  • Whether the current CTA is the right conversion point

Bottom line: the first 30 days should not try to fix everything. They should establish one sharper wedge, one stronger proof asset, and one clearer conversion path that the team can learn from quickly.
